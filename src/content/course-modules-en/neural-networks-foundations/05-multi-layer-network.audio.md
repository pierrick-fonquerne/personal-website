Chapter five. From the neuron to the multilayer network. Stacking neurons to solve XOR, then approximating almost any function.

In chapter four, we proved that a single perceptron cannot compute the XOR function: no straight line separates the points where XOR equals one from those where it equals zero. But we also noticed something. XOR can be written as a combination of functions that are themselves separable: XOR of x one, x two equals, x one or x two, and at the same time, not, x one and x two. This chapter turns that remark into a general method. We will feed neurons with the outputs of other neurons, solve XOR by hand, understand which boundary shapes this wiring can draw, then discover how far the idea reaches: almost every function.

Solving XOR by hand.

The two-assistant analogy. Imagine you are forbidden from answering the question, are the two inputs different, directly. Instead, you may ask two simpler questions to two assistants, then combine their answers. First assistant: is at least one input equal to one? That is the OR function. Second assistant: is it false that both inputs equal one? That is the not-and function, which we call NAND. When exactly one input is one, both assistants say yes at the same time. When both are zero, the first says no. When both are one, the second says no. The two assistants say yes together only in the case where exactly one input is one, which is precisely XOR. So all you have to do is answer yes when both assistants say yes: a simple AND.

The hidden layer. Each assistant is a perceptron. We place them in a hidden layer: an intermediate layer whose outputs are not the final answer, but intermediate questions that the next layer combines. The resulting network, which stacks one or more hidden layers between input and output, is called a multilayer perceptron. We reuse the Heaviside threshold function from chapter four, which equals one if its argument is positive or zero, and zero otherwise. The first hidden neuron computes OR: it equals one as soon as at least one input is one. The second computes NAND: it equals one everywhere, except when both inputs are one at once. The output neuron finally computes the AND of these two values: it equals one only if both hidden neurons equal one, that is, when exactly one original input was one. Three perceptrons, arranged in two layers, therefore compute XOR: something a single perceptron could not do. The key point: in the new coordinates provided by the hidden layer, XOR has become linearly separable again.

What layers let you draw.

The fence analogy. A single neuron is a straight fence in a field: animals on one side, nothing on the other. With a single fence you only mark off a half-field. But with several straight fences, and the rule, an animal is enclosed only if it is on the right side of every fence at once, you fence in a plot of the shape you choose. Formally: a single neuron splits the plane into two half-planes. A layer of several neurons, followed by an output neuron that computes their AND, keeps only the points on the right side of all boundaries at once. That is the intersection of several half-planes, a convex region, a polygon. The more neurons you add, the more sides the polygon has and the more closely it hugs a curve. By adding one more layer, you can take the union of several convex regions and obtain arbitrary shapes, even non-convex ones.

Matrix notation. Writing the weighted sum of each neuron separately becomes unreadable once a layer has hundreds of them. The matrix from chapter two solves this. For a layer, we gather all the weights in a matrix capital W, and all the biases in a vector b. The layer then computes: a equals f of, W times x plus b. In other words: we multiply the input vector by the weight matrix, add the bias vector, then apply the activation function to each component. Each row of the matrix is the weight vector of one neuron. A single line of algebra thus replaces dozens of sums written by hand.

The multilayer perceptron as a composition. A deep network stacks these layers: the output of one becomes the input of the next. It is a composition of functions. But this composition is only useful because a non-linear activation is inserted between each layer. Without it, composing several linear layers would still give a linear function, as we saw in chapter three, and the whole stack would collapse into a single layer. It is exactly the alternation, linear layer, then non-linear activation, that gives the network its expressive power.

How far can we go? The universal approximation theorem. The bump intuition. Take an activation function shaped like a soft step, such as the sigmoid from chapter three. The difference of two slightly shifted sigmoids draws a bump: almost zero everywhere, except a small hump on one interval. By adding up many bumps, well placed and well scaled, you can hug the profile of any continuous curve. A single hidden layer does exactly that. This is the content of the universal approximation theorem, proved by Cybenko in nineteen eighty-nine, and by Hornik, Stinchcombe and White the same year. The statement: for any continuous function on a bounded domain, and for an accuracy as small as we like, there exists a network with a single hidden layer, with finitely many neurons and a suitable activation, such as a sigmoid, that approximates the function as closely as required. Mind the meaning: the theorem guarantees that a good network exists. It does not say that an algorithm can find it from data, nor how many neurons will be needed. Universal does not mean learnable. The rest of the course, from chapter six on, is about that other question: how to set the weights automatically, by learning, rather than by hand as we just did for XOR.

A few exercises to anchor all this. First, check on the four inputs that the construction OR, NAND, then AND does reproduce the XOR table: zero, one, one, zero. Then count the parameters of a network with two inputs, three hidden neurons, one output: nine parameters for the hidden layer, four for the output, thirteen in total. Next, write the matrix form of a small network, watching the dimensions: the number of columns of a weight matrix is the number of neurons in the previous layer, and the number of rows the number of neurons in the current layer. Finally, think about depth versus width: a single layer is enough in theory, but depth often represents the same function with far fewer neurons.

In one sentence: a single neuron draws a line; stacking neurons into layers, with a non-linear activation in between, is enough to draw any boundary, and even to approximate almost any function.

Toward chapter six. We now know that a multilayer network can express anything. The real question remains: how do we set its weights without placing them by hand? The first building block is being able to measure how wrong the network is. Chapter six introduces the forward pass and the cost function, which quantifies the gap between the prediction and the target. It is this measure of the error that, in chapters seven and eight, will guide the automatic adjustment of the weights.

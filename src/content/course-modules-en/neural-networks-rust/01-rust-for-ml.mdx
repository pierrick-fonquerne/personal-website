## What you will learn

- Why Rust: performance, safety, no hidden runtime
- The building blocks we will use: `struct`, `trait`, `Vec<f64>`, `HashMap`
- Setting up the Cargo.toml and the file tree

Rust isn't the default language for ML. But when you want to see exactly where your compute time goes, with no abstraction in between, it's one of the best tools available.

## What you will learn

- Defining a `struct Neuron` with `weights: Vec<f64>`, `bias: f64`, `activation`
- Writing a `forward(&self, inputs: &[f64]) -> f64` method
- Testing it on a hand-verifiable case

We start from $y = f(\sum w_i x_i + b)$ and translate it line by line into Rust. No abstraction, no dependency: just the language's primitives.
